# Нейросетевой классификатор токсичных комментариев

Эксплуатационная практика, Пилюгин Илья Игоревич, МУ им. С. Ю. Витте, 2025.
Предметная область: применение нейронных сетей для обнаружения некорректной и ненормативной лексики.

Сеть получает комментарий на русском языке и возвращает вероятность того, что он токсичен
(оскорбления, нецензурная брань, угрозы). Слова представлены символьными n-граммами, текст
обрабатывает сверточная сеть (PyTorch).

## Запуск на компьютере

```
python -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt
python neurons.py                 # контрольный пример из отчета (подразделы 1.3 и 2.1)
python main.py                    # обучение трех вариантов сети, оценка, рисунки, модель (5-10 минут)
python predict.py "Спасибо, очень полезная статья" "ты тупой идиот"
```

Все серии экспериментов раздела 2 отчета (выбор топологии, подбор характеристик, замер времени,
улучшения) запускаются командой `python experiments.py all`. На процессоре это занимает несколько
часов; готовые результаты уже лежат в папке `results` (файлы `summary_*.json`, `runs_*.json`),
и при повторном запуске посчитанные варианты не обучаются заново.

## Состав

| Файл | Назначение |
|---|---|
| `data/ru_toxicity.csv` | набор данных: 5000 комментариев, поля `text`, `toxic` (TextDetox, часть ru, лицензия OpenRAIL++) |
| `textprep.py` | токенизация, нормализация, символьные n-граммы, искажение слов |
| `dataset.py` | загрузка CSV, очистка, разбиение, загрузчики PyTorch |
| `neurons.py` | нейрон и сверточный фильтр «вручную», проверка средствами PyTorch |
| `models.py` | TextCNN, BiGRU, свёрточно-рекуррентная сеть |
| `training.py` | обучение (Adam, ранняя остановка), метрики |
| `experiments.py` | серии экспериментов |
| `plots.py` | рисунки |
| `main.py` | основной сценарий |
| `predict.py` | проверка комментариев сохраненной моделью |
| `results/` | результаты экспериментов, рисунки, модель `model.pt` |

Источник данных: https://huggingface.co/datasets/textdetox/multilingual_toxicity_dataset (split `ru`).
Пути к файлам заданы относительно каталога программы.
